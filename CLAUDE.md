# Tutor — правила проекта

Личное Anki-подобное приложение. Один пользователь, один компьютер, публичный репозиторий.

## Что где
- `app/` — FastAPI-бэкенд (`main.py` API, `scheduler.py` FSRS + очередь, `decks.py` JSON-колоды, `grading.py` проверка ответов).
- `app/static/` — фронтенд: одна страница, ванильный JS, без сборки.
- `decks/*.json` — колоды. **Файл — источник истины**, прогресс живёт в `data/tutor.db` (в git не идёт).
- `decks/media/` — картинки к карточкам.
- `inbox/` — сюда пользователь кладёт скриншоты тестов для импорта; в git не идёт.
- Запуск: `python run.py` → http://127.0.0.1:8765

## Формат колоды `decks/<id>.json`
```json
{
  "name": "Название", "description": "", "new_per_day": 20,
  "cards": [
    {"id": "q1", "type": "choice",    "question": "…", "options": ["a","b","c"], "answer": 1, "explanation": "…"},
    {"id": "q2", "type": "multi",     "question": "…", "options": ["a","b","c"], "answer": [0, 2]},
    {"id": "q3", "type": "truefalse", "question": "…", "answer": true},
    {"id": "q4", "type": "text",      "question": "…", "answer": "Париж", "accept": ["paris"]},
    {"id": "q5", "type": "flash",     "question": "лицевая", "answer": "оборотная"}
  ]
}
```
- `id` — стабильный ключ прогресса, всегда указывай (`q1`, `q2`…); при смене id прогресс по карточке теряется.
- `image` — имя файла в `decks/media/` (необязательно). `explanation` показывается после ответа.
- `text`: сравнение без учёта регистра/пунктуации, числа сравниваются как числа («9,8» == «9.8»).

## Импорт теста из скриншотов (типовая задача)
1. Прочитать все картинки из указанной папки (обычно `inbox/…`) инструментом Read.
2. Перенести вопросы в JSON: правильный тип на вопрос (один вариант → `choice`, «отметьте все» → `multi`, утверждение → `truefalse`, открытый ответ → `text`), сохранить формулы/единицы, при необходимости добавить `explanation`.
3. Если ответы на скриншотах не отмечены — решить самому и пометить сомнительные в `explanation` словом «проверить».
4. Записать `decks/<slug>.json`, проверить: `python -c "from app.decks import load_deck, validate_deck; validate_deck(load_deck('<slug>'))"`.
5. Если сервер запущен — нажать «Перечитать файлы» в UI или `curl -X POST localhost:8765/api/reload`.

## Git
- Коммитить логичными шагами, пушить в `origin main`.
- Перед каждым коммитом проверять, что не утекают чувствительные данные: `data/`, `inbox/`, `.env`, скриншоты с личной информацией, e-mail. Репозиторий публичный.
