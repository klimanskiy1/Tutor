# Tutor

Личная «Anki»: загружаешь тесты (английский, физика, что угодно), решаешь каждый день,
программа сама решает, что и когда показать (интервальное повторение на алгоритме FSRS —
том же, что в современном Anki).

Типы карточек: один вариант, несколько вариантов, верно/неверно, ввод текста, обычная карточка с самооценкой.

## Запуск
```
pip install -r requirements.txt
python run.py
```
Откроется http://127.0.0.1:8765.

## Колоды
JSON-файлы в `decks/` — формат описан в `CLAUDE.md`. Можно создавать и править прямо в приложении.
Прогресс хранится в `data/tutor.db` (в репозиторий не попадает).
